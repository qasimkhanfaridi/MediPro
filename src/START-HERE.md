# ?? Quick Start - Run MediPro

## Easiest Way to Start Both Projects

### Option 1: Double-Click (Recommended)
Just **double-click** this file:
```
start-medipro.bat
```

This will automatically open two windows and start:
- ? Backend API ? http://localhost:5020
- ? Frontend Web ? http://localhost:5173

---

## Option 2: Manual Commands

### Terminal 1 - Start Backend API
```powershell
cd B:\MediPro\src\MediPro.Api
.\start-api.ps1
```

### Terminal 2 - Start Frontend Web  
```powershell
cd B:\MediPro\src\MediPro.Web
.\start-web.ps1
```
