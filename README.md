# MediPro — Documentation Hub

This folder contains planning and delivery documents for **MediPro**, a B2B medicine ordering and distributor operations platform for Pakistan. Initial focus: **Rawalpindi / Islamabad**, mobile-first web, with a path to native apps via shared APIs.

## How to use this package

1. **Stakeholders / sponsors:** Start with Executive Overview → Charter → BRD → Milestones.  
2. **Product / BA:** BRD + PRD + User Stories.  
3. **Engineering:** PRD + Architecture + Data Model.  
4. **Compliance / ops:** Risks & Compliance + BRD sections on regulatory positioning.
