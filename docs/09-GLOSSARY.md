# Glossary — MediPro

| Term | Definition |
|------|------------|
| **MediPro** | Working product name for this B2B medicine ordering platform. |
| **Booker** | Field salesperson who visits medical stores to collect orders (traditional model). |
| **Distributor** | Licensed pharmaceutical distributor supplying retailers; primary **admin** tenant in MediPro. |
| **Medical store / Pharmacy (B2B)** | Licensed retail outlet purchasing inventory for resale—not end-consumer channel in this BRD. |
| **SKU** | Stock keeping unit; distinct orderable item including pack configuration. |
| **Salt / composition** | Active pharmaceutical ingredient(s) listed generically (e.g., “Paracetamol”)—used for search/filter. |
| **MRP** | Maximum retail price where displayed for reference per trade practice. |
| **Trade price** | Wholesale price offered by distributor to store—may differ by agreement. |
| **Pack** | Unit of sale (e.g., 10 tablets, 120 ml bottle). |
| **Tenant** | Isolated organizational partition in software; one distributor per tenant in multi-tenant SaaS models. |
| **BRD** | Business Requirements Document—*why* and business-level *what*. |
| **PRD** | Product Requirements Document—detailed *what* for engineering and QA. |
| **MVP** | Minimum viable product—smallest release that validates core value. |
| **API-first** | Backend exposes stable APIs so web and mobile clients share the same logic. |
| **Mobile-first** | UI/UX designed for phone screens first, then adapted to larger screens. |
| **PWA** | Progressive Web App—installable web with optional offline behaviors. |
| **DRAP** | Drug Regulatory Authority of Pakistan—regulates medicines; positioning must respect licensed trade. |
| **NTN** | National Tax Number (Pakistan)—may appear in B2B onboarding. |
| **JWT** | JSON Web Token—common format for API authentication tokens. |
| **RBAC** | Role-based access control—permissions derived from user roles. |
| **UAT** | User acceptance testing—business sign-off before release. |
| **Idempotency** | Repeating the same request does not duplicate side effects (important for order APIs). |
