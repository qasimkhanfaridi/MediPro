# Executive Overview (One Page) — MediPro

## Problem

Pharmaceutical distributors rely heavily on **field visits** and manual order-taking. **Fuel, vehicles, and salaries** increase cost pressure while **phone and paper orders** drive pricing and SKU errors.

## Solution

**MediPro** — a **mobile-first B2B web platform** that lets **verified medical stores** browse the distributor catalog, **place accurate orders**, and **track status**, while **distributor staff** manage **stores, catalog, bulk Excel imports, orders, and stock signals** in one system.

## Why now

Existing distribution relationships and a **concentrated pilot region (Rawalpindi / Islamabad)** allow **fast validation** with measurable KPIs before broader rollout or optional **multi-tenant** expansion.

## Scope (MVP)

- Mobile-friendly web for stores; admin console for operations.
- Roles: distributor admin vs store user; optional approvals for new stores.
- Catalog with search (product, company, salt); cart and orders with audit-friendly snapshots.
- Bulk product import; notifications for core operational events; inventory model per agreed MVP.

## Phase after MVP

- **Native apps** using the **same APIs** (minimal duplicate logic).
- **Online payments** once order flow and reconciliation are stable.
- **Deeper ERP integration** if needed.

## Risks (headline)

- **Stock/pricing accuracy** must match operations discipline.
- **B2B-only positioning** and licensed onboarding for Pakistan regulatory context.
- **Adoption** requires training and support—not “launch and forget.”

## Success (pilot)

Define numeric targets before pilot: **active ordering stores**, **order accuracy**, **time to confirm**, **ops time saved**.
