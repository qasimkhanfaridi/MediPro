# RACI & Stakeholder Matrix — MediPro

## 1. RACI definitions

| Letter | Meaning |
|--------|---------|
| **R** | Responsible — does the work |
| **A** | Accountable — final decision (only one **A** per row) |
| **C** | Consulted — two-way input |
| **I** | Informed — one-way updates |
